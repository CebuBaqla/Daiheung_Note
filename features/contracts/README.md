# 계약내역 가져오기

1. 관리자 → 현장 상세 → 새 내역 가져오기에서 XLSX, CSV, JSON 또는 PDF 파일을 엽니다.
2. 엑셀은 내역 시트를 선택합니다. 빈 행을 제외한 원본 셀을 표로 보여 줍니다. PDF는 디지털 텍스트를 먼저 읽고, 필요한 경우 스캔 문자 인식으로 다시 엽니다. PDF의 칸은 텍스트 조각이며 원본 열과 정확히 일치하지 않을 수 있습니다.
3. 한 검색창에 단어를 띄어쓰기로 입력합니다. 모든 단어가 한 행의 원문에 포함된 행만 표시됩니다. 예: `표지판 철거 변경`.
4. 원본 표 헤더의 드롭다운에서 품명·규격·단위·수량 열을 직접 지정합니다. 한 역할은 한 열에만 지정할 수 있습니다. 필요 없는 열은 숨기고, 숨긴 열 초기화로 다시 표시할 수 있습니다.
5. 필요한 행을 체크해 시공 관리 리스트에 추가합니다. 품명과 규격은 `품명 · 규격`으로 결합하고, 지정한 열의 수량·단위를 채웁니다. 리스트에서 직접 수정할 수 있으며 검색어나 시트를 바꿔도 선택한 품목은 유지됩니다.
6. 시공 관리 대상 품목 확정 등록은 기존 현장의 계약 목록 전체를 교체합니다. 선택하지 않은 행은 등록하지 않습니다.

표 헤더와 열 역할은 자동 판정하지 않습니다. 수량 셀에 숫자가 둘 이상 있거나 숫자가 없으면 빈칸으로 남겨 직접 확인하게 합니다. `변경`처럼 상단 헤더에만 적힌 단어는 아래 개별 행 검색에 포함되지 않습니다.

## 저장 방식

시공 관리 대상 품목 등록은 기존 `dh_import_contract` RPC에 `{ code, name, unit, target, weight: 1 }` 목록을 보냅니다. `code`는 파일 지문과 원본 위치로 만든 행 ID입니다. 기존 검토 형식 `dh-contract-review/1`에 가짜 구역이나 열 정보를 넣지 않습니다. 따라서 새 등록은 `contract_review_import` 원본·검토 JSON 이력에 추가되지 않습니다. 화면의 이전 검토 이력과 비고 조회 기능은 기존 기록에 대해 유지됩니다.

파일·열 역할·시공 관리 리스트 상태는 화면 메모리에만 있습니다. 파일을 바꾸거나 창을 닫으면 초기화됩니다. 한 파일은 25MB, 한 시트/문서는 20,000행, PDF는 100쪽 이내로 제한합니다.

## 계약 수량 진행현황

`contracts_progress.sql`을 기존 V6 및 계약내역 설치 후 Supabase SQL Editor에서 실행합니다. 관리자 화면의 현장 목록에서 진행률 숫자를 누르면 현재 계약 내역에 등록된 품목별 계약·진행·잔여·초과 수량을 조회하고, 표시된 결과를 XLSX로 다운로드할 수 있습니다.

진행 수량은 계약 품목에 연결된 작업계획의 작업 중 **제출 완료된 작업종료 보고**에 기록된 실제 수량만 합산합니다. 계약 내역에 올리지 않은 부자재, 연결되지 않은 작업, 제외된 계약 품목은 집계하지 않습니다. 품목별 진행률은 100%까지만 표시하고 초과 시공량은 별도 열에 표시합니다. 현장 목록의 진행률은 현재 계약 품목별 진행률의 단순 평균입니다. 단위가 다른 수량을 합산하지 않습니다.

조회 함수가 없거나 실적 열 구성을 확인하지 못하면 진행률은 `0%` 대신 `조회 실패`로 표시됩니다. 이 파일 묶음에는 기본 V6 설치 SQL이 없으므로 실제 서버의 `report_task` 열 이름과 작업종료 연결 구조를 적용 전에 확인해야 합니다.
